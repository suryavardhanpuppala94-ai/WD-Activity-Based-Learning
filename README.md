# Web Development Assignment

## Project Overview

This project contains three websites developed using HTML and CSS.

1. Personal Portfolio Website
2. Student Registration Form
3. College Information Website

The HTML and CSS are written in the same file for each website.

## 1. Personal Portfolio Website

**File name:** `index.html`

The Personal Portfolio Website introduces a student and displays information about their education, skills, projects, and contact details.

**Sections included:**
- About
- Skills
- Education
- Projects
- Contact

The navigation bar allows users to move to different sections of the same webpage.

## 2. Student Registration Form

**File name:** `studentregistration.html`

The Student Registration Form demonstrates how HTML form elements are used to collect student information.

**Features included:**
- First name and last name
- Email address
- Mobile number
- Date of birth
- Branch selection
- Gender selection using radio buttons
- Interests using checkboxes
- Submit and Reset buttons

This is a demonstration form. It does not save information to a server.

## 3. College Information Website

**File name:** `college.html`

The College Information Website provides basic information about a college.

**Sections included:**
- About
- Courses
- Admissions
- Facilities

The navigation bar allows users to move directly to each section. The website uses a simple layout and light colours without pictures or forms.

## Technologies Used

- **HTML5:** Used to create the structure and content of the webpages.
- **CSS3:** Used to add colours, spacing, layouts, borders, and hover effects.

No JavaScript is used in these websites.

## How to Run the Websites

1. Save each website's code in a separate `.html` file.
2. Keep the three files in your project folder.
3. Open any HTML file in a web browser such as Google Chrome.
4. Click the navigation links to explore the different sections.

## Customisation

Before submitting the assignment, replace sample details with your own information where necessary.

Examples include:
- Student name and initials
- Email address and location
- College name and information
- Course and project details

## Conclusion

This project demonstrates basic webpage development using HTML and CSS. It includes a personal portfolio, a student registration form, and a college information website. These websites provide practice with webpage structure, navigation links, styling, and HTML form elements.
